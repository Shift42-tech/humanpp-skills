# humanpp-implementation-loop

## Purpose

Guide implementation work with opening checks, scoped execution, validation, correction passes, and final reporting.

Coverage: `Implementation <-> Review`

## Required outputs

- Opening checks
- Source checks
- Local implementation plan
- Stop conditions before editing
- Scope discipline notes
- Validation evidence
- Final report

## Rules

- Avoid unrelated refactors.
- Do not change dependencies without approval.
- Avoid broad architecture changes without explicit approval.
- Do not claim checks or remote actions that were not actually performed.
