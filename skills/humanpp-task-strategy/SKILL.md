# humanpp-task-strategy

## Purpose

Turn a rough request, discussion, feature idea, bug report, or stakeholder note into a bounded execution strategy.

Coverage: `Analysis -> Strategy`

## Required outputs

- Analysis summary
- Sources inspected
- Source alignment
- Current state
- Target outcome
- Scope and out of scope
- Assumptions
- Risks and stop conditions
- Implementation strategy
- Validation plan
- GitHub issue draft
- Agent opening prompt
- Review checklist
